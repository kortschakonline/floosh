## 1.6.0 — Dateien auf das Menüleisten-Symbol ziehen

Die Ablage lässt sich jetzt so benutzen, wie man es erwartet: **Datei greifen, über das floosh-Symbol in der Menüleiste halten — das Fenster klappt auf — und irgendwo darin fallen lassen.** Ablegen geht auch direkt auf dem Symbol.

Dafür hat floosh die Menüleiste selbst übernommen (eigener `NSStatusItem` statt SwiftUIs `MenuBarExtra`). Der Grund: Das Fenster von `MenuBarExtra` schließt sich, sobald eine andere App aktiv wird — und genau das passiert, wenn man im Finder die Maus auf einer Datei drückt. Ziehen war damit unmöglich.

Was das mitbringt:

- **Spring-Loading**: Beim Darüberziehen öffnet sich das Fenster von selbst und bleibt offen, solange der Zeiger darin ist.
- **Das ganze Fenster ist Ablage-Ziel** — nicht nur die Ablage-Karte. Ist die Ablage ausgeblendet, wird sie beim ersten Ablegen automatisch eingeblendet.
- **Eigenes Einstellungsfenster**: größenveränderbar und scrollbar, damit der Anzeige-Tab nicht mehr über den Bildschirmrand hinausreicht.
- Fenster schließt per Klick daneben, Escape oder erneutem Klick auf das Symbol.

**Installation**: DMG öffnen, floosh nach *Programme* ziehen. Beim ersten Start ggf. Rechtsklick → Öffnen (ad-hoc-signiert).
